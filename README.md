# Plenty

Food for today. A next step toward the person you want to become.

Plenty is the United Under God / Life Produces Life food-pantry app. First pantry: **Vidalia, Georgia**.

Live: https://plenty.unitedundergod.org

## Doors

- **I need food** — hours, what is available this week, household, visit check-in
- **I want to help** — volunteer (pickup, setup, serve, delivery) and donate (food, money, space, vehicles)
- **I run this pantry** — setup, inventory, people, distribution days, promote
- **A path, not only a bag** — optional. Food is never gated on it.

## Stack

Next.js on Vercel. Shared Life Produces Life Supabase (`plenty_*` tables). Shared ecosystem identity (GoTrue).
